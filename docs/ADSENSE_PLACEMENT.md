# Google AdSense 배치·콘텐츠 정책

## "게시자 콘텐츠가 없는 화면에 Google 게재 광고" 거절 대응

AdSense는 **실제 게시자 콘텐츠가 있는 페이지만** 광고를 노출해야 합니다. 아래 네 가지 해결 방법이 반영되어 있는지 확인했습니다.

### 원인(자주 발생)

- **`adsbygoogle.js`를 `layout` 등에서 전 페이지에 로드**하면, 애드센스 계정에서 **자동 광고(Auto ads)** 가 켜져 있을 때 로그인·OAuth 콜백·마이페이지처럼 **본문이 거의 없는 URL**에도 광고가 들어갈 수 있습니다.
- 구글은 이를 **게시자 콘텐츠가 없는 화면에 광고**로 정책 위반으로 처리할 수 있습니다.

### 코드 측 조치(이 저장소)

- `components/AdSenseRouteScript.tsx` + `lib/adsenseAllowedPath.ts`  
  **홈·이미지 비교·결과·도감·랭킹·게시판(작성/수정 제외)·FAQ·문의·약관 등**에만 `adsbygoogle.js`를 로드합니다.
- **`/login`, `/auth/*`, `/profile`, `/my/*`, `/board/new`, `/board/edit`** 등에서는 스크립트를 넣지 않습니다.

### 계정(애드센스)에서 확인할 것

- [광고] → [개요] 또는 사이트 설정에서 **자동 광고** 사용 여부를 확인하고, 필요 시 끄거나 URL 그룹으로 제한합니다.
- 수정 후 [정책 센터](https://www.google.com/adsense)에서 **재검토**를 요청합니다.

---

### 1. 충분한 텍스트 확보 (최소 500~1,000자 이상)

| 페이지 | 조치 | 상태 |
|--------|------|------|
| **홈 (`/`)** | 히어로 + 5개 문단(서비스 소개, 도감·랭킹·공유, 감정 결과, MBTI 유추, 개인정보·분석 방식). 600자 이상 유의미한 텍스트 확보 | ✅ |
| **이미지 비교 (`/image-compare`)** | 제목·설명 + "이용 방법" 섹션 4문단(이용법, 표정에 따른 결과, 공유 방법, 개인정보). 결과 없을 때도 500자 이상 | ✅ |
| **결과 (`/result/[id]`)** | 포켓몬 이름·타입·설명 + 참고 문구(t.result.reference) + MBTI 블록 설명. 페이지별 고유 텍스트 확보 | ✅ |

- 모든 광고 노출 페이지에 **정보성 텍스트**가 광고 위·주변에 충분히 있음.

---

### 2. 콘텐츠 보강 (이미지/영상 위주 → 정보성 글 추가)

- **홈**: 비디오 배경 + **텍스트 섹션(SEO 본문)** 이 메인. 버튼 위·아래에 서비스 설명·이용법·개인정보 문구로 가치 부여.
- **이미지 비교**: 업로드 UI와 결과 카드 외에 **"포켓몬 닮은꼴 찾기 이용 방법"** 등 정보성 문단 배치.
- **결과**: 포켓몬 이미지·카드와 함께 **참고 문구·MBTI 설명** 등 텍스트 노출.

→ 이미지/영상만 있는 화면 없이, **정보성 글이 포함된 페이지만** 광고 노출.

---

### 3. 색인 확인 (구글 서치 콘솔)

- **robots.txt** (`app/robots.ts`): `allow: '/'`, `disallow: '/auth/', /profile, /my/, /board/new, /board/edit'`, `sitemap` URL 노출. ✅
- **sitemap.xml** (`app/sitemap.ts`): 홈·이미지 비교·도감·게시판·랭킹·결과(정적 경로)·약관·개인정보·문의·FAQ 등 포함. ✅
- **layout 메타**: `metadataBase`, `description`, `openGraph`, `robots: { index: true, follow: true }` 등 설정됨. ✅

**개발자가 할 일**:  
배포 후 [Google Search Console](https://search.google.com/search-console)에 사이트 등록 후,  
- URL 검사로 중요 페이지 수동 요청  
- Sitemap 제출  
- 색인 생성·크롤링 상태 확인  

→ 구글 봇이 콘텐츠를 정상 크롤링하는지 반드시 확인.

---

### 4. 불필요한 광고 코드 제거 (빈 페이지·카테고리)

| 화면 | 광고 노출 여부 | 비고 |
|------|----------------|------|
| **홈** | ✅ 노출 | 본문 5문단 아래에만 배치 |
| **이미지 비교 (결과 없음)** | ❌ **미노출** | `results && results.length > 0` 일 때만 `<AdSenseSlot>` 렌더. 업로드만 있는 화면에는 광고 코드 없음 |
| **이미지 비교 (결과 있음)** | ✅ 노출 | 결과 카드 + 이용 방법 텍스트 아래 |
| **결과 (`/result/[id]`)** | ✅ 노출 | 포켓몬 카드·설명·참고 문구·MBTI 등 콘텐츠 아래 |
| **도감·랭킹·게시판 등** | ❌ 광고 없음 | 현재 광고 배치 페이지는 홈·이미지 비교(조건부)·결과만 해당 |

- **빈 페이지·콘텐츠 없는 카테고리에는 광고 코드를 두지 않음.**  
- 이미지 비교는 **결과가 있을 때만** 광고 영역을 렌더하므로, "콘텐츠 없는 화면"에 해당하지 않도록 처리됨.

---

### 현재 광고 노출 위치 요약

1. **홈 (`/`)**: SEO 본문(5문단, 600자 이상) **아래**
2. **이미지 비교 (`/image-compare`)**: **비교 결과가 있을 때만** 결과 섹션 아래 (결과 없으면 광고 미렌더)
3. **결과 (`/result/[id]`)**: 포켓몬 카드·참고 문구·MBTI 등 **콘텐츠 아래**

### 새 페이지에 광고 추가 시

- 해당 페이지에 **최소 500자 이상의 유의미한 텍스트**가 있는지 확인.
- **본문/결과 등 실제 콘텐츠 아래**에만 배치.
- 빈 페이지·로딩 전용·에러 전용 화면에는 광고 코드를 넣지 않기.

---

### 재심사 요청

수정 후 AdSense 정책 센터에서 **사이트 재심사**를 요청하세요.

- [정책 센터](https://www.google.com/adsense) → 해당 이슈 → **수정 요청** 또는 **재검토 요청**
- 요청 시 예시 문구:  
  "콘텐츠 없는 화면에서는 광고를 제거했습니다(이미지 비교는 결과가 있을 때만 광고 노출).  
  각 페이지에 500자 이상 정보성 텍스트를 두었고, 빈 페이지에는 광고 코드를 넣지 않았습니다.  
  robots.txt·sitemap을 제공하며 Search Console에서 색인을 확인합니다."
